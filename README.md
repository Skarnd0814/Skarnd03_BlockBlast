# 🧩 Block Blast (2D Block Puzzle Game)

> **Unity 6**로 개발한 모바일 블록 퍼즐 게임입니다. (Block Blast 모작)  
> 8×8 판 위에 블록을 끌어다 놓아 **가로·세로 줄을 완성해 지우는** 퍼즐 게임으로, 항상 3개의 블록을 모두 쓸 수 있는 길이 존재하도록 설계된 **세트 보장 블록 생성**과 콤보 시스템을 통해 "길을 찾아내는" 재미를 제공합니다.

---

## 🛠️ 개발 환경 및 사용 기술 (Tech Stack)

* **Engine:** Unity 6.3 LTS (6000.3.25f1)
* **Language:** C#
* **Render Pipeline:** 2D Universal Render Pipeline (URP)
* **UI System:** TextMeshPro (Fredoka 폰트), Canvas Scaler (1080×1920 기준)
* **Input:** Input System (마우스 + 터치 공통 Pointer 입력)
* **Platform:** Android (세로 화면 고정, 화면 비율 자동 대응)
* **Assets:** AI 생성 스프라이트 (Bing AI / Nano Banana), SFX (ElevenLabs), BGM (SUNO AI)

## ✨ 핵심 기능 (Features)

* 🎬 **타이틀 & 메뉴 화면**
  * 블러 처리된 배경 위 게임 로고, `TOUCH TO START` 깜빡임, 제작자 이름 표시
  * 화면 터치 시 블러 배경이 서서히 걷히며 로고가 메뉴 로고 위치·크기로 부드럽게 이동하는 끊김 없는 씬 전환
  * 메뉴 진입 시 PLAY / 설정 버튼이 아래에서 떠오르며 페이드 인 (등장 중 입력 차단)
  * 메뉴 화면에 최고 점수(BEST) 표시
  * 설정 팝업에서 BGM / 효과음 볼륨 조절
* 🧱 **8×8 게임판 & 블록**
  * 코드로 자동 생성되는 8×8 판, 판 크기는 상수 하나로 변경 가능
  * 1칸 ~ 3×3까지 29종 블록 모양 (일자, 네모, 직사각형 2×3·3×2, L, 큰 L 5칸 4방향, T, S/Z 등)
  * 트레이에 블록 3개를 작게 표시, 3개를 모두 사용하면 새로 생성
* 🖐️ **드래그 & 배치**
  * 블록을 집으면 원래 크기로 부드럽게 커지고, 블록의 아래쪽 끝이 손가락 위에 오도록 띄워서 표시 (세로로 긴 블록도 가려지지 않음)
  * 가장 가까운 칸으로 자동 정렬, 놓을 수 없는 자리면 트레이로 미끄러지듯 복귀
  * 드래그 감도(손가락 이동 대비 블록 이동 배율) 조절 가능
  * **배치 미리보기**: 놓일 칸에 블록 색의 반투명 그림자 표시
  * **줄 완성 예고**: 놓으면 완성될 줄의 블록들이 드래그 중인 블록 색으로 깜빡임
* 🧠 **세트 보장 블록 생성 (Placement Solver)**
  * 판 복사본 위에서 실제로 블록을 놓아 보며(줄 삭제 포함) 해법 경로를 만든 뒤, 그 경로에 맞는 블록 3개를 순서를 섞어 제공
  * 빽빽한 판에서도 3개를 모두 사용할 수 있는 길이 항상 존재 → 게임 오버는 운이 아닌 플레이어의 판단으로 결정
  * 판에서 블록으로 둘러싸인 빈칸(구멍)을 Flood Fill로 탐색, 구멍과 정확히 같은 모양의 블록 출현 확률 증가
  * 모양별 출현 가중치: 1×4·1×5·2×3·3×2·3×3 같은 큰 블록 위주로 등장해 한 번에 크게 터뜨리는 손맛 강화
  * 1~3칸 작은 블록은 큰 블록을 놓을 자리가 없을 때만 등장
  * 난이도 조절: 보장 확률, 모양별 가중치, 해법 경로의 줄 삭제 선호도, 구멍 맞춤 가중치
* 💥 **줄 삭제 & 점수**
  * 가로·세로 줄 동시 삭제 지원 (교차 칸 포함)
  * 블록 배치 점수(칸 수) + 줄 삭제 점수(줄 수² 비례)
  * 점수가 오를 때 숫자가 빠르게 올라가는 카운트업 + 펀치 스케일 애니메이션
  * `PlayerPrefs` 기반 최고 점수(BEST) 영구 저장 및 실시간 표시
* 🔥 **콤보 시스템**
  * 2줄 이상 동시 삭제 시 `GREAT!` / `EXCELLENT!` / `AMAZING!` 칭찬 문구 (검은 테두리)
  * 연속 줄 삭제 시 `COMBO N` 표시, 줄을 못 지운 배치가 3번 연속되면 콤보 초기화
  * 콤보가 이어질수록 줄 삭제 점수 배율 증가
* 🎞️ **시각 연출 (Juice & VFX)**
  * 게임 시작 시 빈 칸이 화면 아래에서 물결처럼 솟아오르며 판이 채워지는 등장 연출
  * 새 블록 3개가 차례로 톡톡 튀어나오는 등장 연출
  * 줄 삭제 시 블록이 커졌다가 작아지며 사라지는 순차(물결) 효과
  * 게임 오버 시 판 전체가 튀어 올랐다가 중력으로 우수수 무너지는 연출
  * 게임 오버 팝업이 아래에서 올라오며 페이드 인
* ⏸️ **게임 흐름**
  * 놓을 수 있는 블록이 하나도 없으면 게임 오버 (판 무너짐 → 결과 팝업)
  * 게임 오버 화면: 최종 점수 / 최고 점수 / NEW BEST 표시, 다시 시작 / 홈
  * 일시정지: 게임 정지(`Time.timeScale`), 볼륨 조절, 다시 시작 / 홈 / 계속하기
* 🎵 **오디오 시스템**
  * 씬 전환 시에도 끊기지 않는 싱글톤 SoundManager (`DontDestroyOnLoad`, 프리팹으로 모든 씬 배치)
  * BGM / 효과음 볼륨 분리 조절 및 `PlayerPrefs` 저장
  * 블록 집기·놓기·실패, 줄 삭제(2줄 이상 시 랜덤), 판 채우기·무너짐, 블록 등장, 게임 오버, 신기록 등 상황별 효과음
* 📱 **모바일 대응**
  * 화면 주사율에 맞춘 60~120fps 실행 (안드로이드 기본 30fps 해제)으로 부드러운 드래그
  * 화면 비율(9:16 ~ 20:9, 태블릿)에 따라 카메라 크기 자동 조절로 판·트레이 잘림 방지, 배경 자동 확대
  * Android Adaptive 아이콘 (런처 모양에 맞춰 잘려도 로고가 온전히 보이도록 구성)
  * 노치·펀치홀 영역 렌더링 제외로 상단 UI 가림 방지
  * 씬 전환 직후 버튼 오작동 방지 (터치를 뗄 때 전환)
